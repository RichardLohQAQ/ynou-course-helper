# 隐私与权限

## 数据保存在哪里

- 课程缓存、账号区分标识、进度、运行记录、窗口尺寸和模型配置保存在当前浏览器的扩展存储中。
- 模型 Key 使用浏览器本地存储保存，不是经过额外加密的密码保险箱；不要向不信任的人共享浏览器用户目录。
- 正在处理的题目与答案保存在运行状态中。作业诊断导出排除题干和答案正文，但仍可能包含账号区分标识、课程链接、成绩和操作时间。
- 视频诊断会记录页面播放、退出事件及部分播放占用标记，标记值会做限制和遮盖。它不是“完全匿名”的报告，公开前仍应检查并脱敏。

## 数据发送给谁

扩展通过教学平台网页执行课程操作。只有使用模型功能时，才向用户配置的 API 发送必要的题目文字、选项和模型请求；获取可用模型列表只调用该 API 的模型列表接口。

模型请求不附带教学平台的 Cookie，Key 只作为配置 API 的授权头发送，拒绝 HTTP 重定向。扩展没有项目作者运营的数据收集服务器或遥测上报服务。第三方模型供应商的数据保留政策需由使用者自行了解。

## 浏览器权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存课程缓存、设置和运行状态。 |
| `activeTab` | 用户操作扩展时识别当前网页。 |
| `alarms` | 后台唤醒，检查任务及窗口状态。 |
| `https://teach.ynou.edu.cn/*` | 读取课程页面、操作页面控件和管理相关任务。 |
| 可选 HTTPS / 本机 HTTP 域名访问 | 获取模型列表与调用用户指定的模型接口；点击配置操作时为对应域名请求授权。 |

可选权限声明中包含 HTTPS 通配范围，以支持用户自定义 API 域名；使用时按填写的域名申请，实际授权范围可在扩展管理页查看。

## 清除与反馈

模型设置中的“清除配置”删除当前模型设置。卸载扩展可移除其浏览器本地存储，但不会删除你已经导出的文件，也不会撤销已经提交到平台的作业。

反馈问题时，请提供删去个人信息后的必要日志片段，不要公开原始诊断文件、账号密码、API Key 或完整题库。
