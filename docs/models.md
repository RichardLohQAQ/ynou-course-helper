# 模型接口与配置

当前保存一组正在使用的 API 地址、Key 和模型。切换服务时请重新填写并保存。

## 接口约定

- 支持 OpenAI 兼容的文字对话接口，使用 Bearer API Key。
- 输入 `https://api.example.com/v1` 时，访问 `GET /v1/models` 和 `POST /v1/chat/completions`。
- 输入完整的 `/chat/completions` 或 `/models` 地址时，会自动移除该后缀。
- 输入只有域名的地址时，会补上 `/v1`；自定义路径前缀会保留。
- 远程地址必须使用 HTTPS。本机 `http://localhost` 和 `http://127.0.0.1` 可用，但仍需填写接口接受的非空 Key。
- 不接受含用户名、密码、查询参数或锚点的 API 地址。

模型列表支持 `data: [{id: "model-name"}]`，也兼容 `models` 数组。获取列表只发送 Key，不包含题目。某些供应商提供的模型列表含语音、图像等模型，需自行选择支持文字对话的型号。

## 解题请求

发送内容包含系统提示、文字题干、选项及题号等必要结构。每组最多 12 题，累计文字较长时会提前拆组。当前配图不传给模型。

回答要求为 JSON，校验题号、题数、单选/多选取值和填空数量。一次复核仍不确定的题会采用模型给出的最佳答案继续填写并提交，同时在运行记录中保留疑问题号；格式检查通过并不代表答案一定正确。

停止作业会取消当前请求；服务端已经开始的请求是否计费由供应商决定。不要在公开 Issue 中粘贴 API Key 或带有 Key 的请求头。

## 常见错误

| 情况 | 处理 |
| --- | --- |
| 401 / 403 | 检查 Key 是否适用于当前 API 及模型，确认账户权限。 |
| 获取列表返回 404 / 405 | 核对地址；若服务不提供列表接口，手动填写模型名称。 |
| 429 | 检查额度或调用频率限制。 |
| 无法连接或超时 | 检查网络、域名授权与服务状态。 |
| 返回非 JSON / 输出不完整 | 确认模型支持文字对话并能按要求输出完整 JSON。 |

Key 保存在浏览器扩展本地存储中。清除配置可删除当前模型配置；这不会撤销供应商已经签发的 Key。
