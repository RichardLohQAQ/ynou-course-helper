# 云开课程助手｜云南开放大学课程助手

**视频连播 · 网上作业 · 离线作业进度，一处查看。**

`ynou-course-helper` 是适用于云南开放大学教学平台（`teach.ynou.edu.cn`）的 Chrome / Edge 扩展。一次扫描课程，缓存视频、网上作业和离线作业状态，在可调整大小的独立窗口中查看进度。

项目名中的 `ynou` 取自 Yunnan Open University，`course-helper` 意为“课程助手”。这是个人维护的开源项目，与学校或教学平台没有官方隶属关系。

## 功能

| 功能 | 说明 |
| --- | --- |
| 统一扫描 | 从教学平台首页逐科扫描并缓存三类进度，区分当前登录账号。 |
| 视频连播 | 按目录顺序播放，在当前视频页右侧切换；一批结束后核对平台实际进度。 |
| 网上作业 | 使用自己配置的模型生成答案，校验后填写、提交，并打开成绩与解析；按课程要求的份数分批处理。 |
| 离线作业 | 扫描并区分未提交、已提交待批改、已批改等状态；不自动生成或上传离线作业。 |
| 进度面板 | 总览展示三类进度，切换页签后查看对应类别的课程明细。 |
| 模型设置 | 自定义 OpenAI 兼容 API、API Key 和模型；支持获取可用模型列表及手动填写模型名称。 |
| 独立窗口 | 拖动边缘调整大小、记忆窗口尺寸；当前浏览器最后一个普通窗口关闭后，助手窗口随之关闭。 |
| 运行记录 | 查看本地运行记录，导出诊断信息。 |

视频和网上作业以平台实际进度为准。可处理的条目已用尽但平台尚未满额时，会记录跳过并继续后续科目；待平台更新后可重新扫描。已提交的离线作业可能要等老师批改才计入平台进度。

## 安装

支持 Chrome / Edge 116 及以上版本，无需安装 Node.js 即可使用扩展。

1. 在 [Releases 下载页面](https://github.com/RichardLohQAQ/ynou-course-helper/releases/latest) 下载 `ynou-course-helper-版本号.zip` 并解压到固定文件夹。
2. 打开 `chrome://extensions`，Edge 则打开 `edge://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
4. 登录教学平台，**刷新已打开的平台页面**，再点击工具栏中的“云开课程助手”。

也可以下载或克隆源码，在第 3 步直接选择仓库中的 **`extension/`** 文件夹。

更新时，替换原文件夹内的扩展文件，在扩展管理页点击“重新加载”，然后刷新教学平台页面。请先停止正在运行的任务。

## 使用

1. 在已登录的教学平台首页打开助手，点击 **扫描全部课程**。
2. 扫描完成后，根据需要切换 **视频连播 / 网上作业 / 离线作业**。
3. 视频页签点击 **使用缓存开始学习**；网上作业页签点击 **使用缓存开始作业**。
4. 用对应的“停止”按钮结束任务。离线作业页签用于查看提交与批改状态。

课程核对会返回首页，再进入对应课程读取最新进度。运行中请保留平台首页及当前任务页面，避免同时手动操作同一份作业或打开多个视频。

### 配置模型

**没有内置 API Key。未配置模型时，网上作业功能无法启动；扫描和视频功能可以正常使用。**

1. 展开 **模型设置**，填写自己的 API 地址和 API Key，例如 `https://api.example.com/v1`。
2. 点击 **获取可用模型**，允许浏览器访问你填写的 API 域名。
3. 选择支持文字对话的模型，或手动输入模型名称，再点击 **保存设置**。

模型服务需要兼容 `POST /chat/completions`；自动获取列表使用 `GET /models`。若服务没有模型列表接口，可手动填写。模型调用可能产生服务商费用。

题目按每组最多 12 题及文字长度拆分请求。不确定的题会单独复核，整份答案通过题号、选项和完整性检查后才提交。当前仅处理文字题干与选项，忽略配图，模型答案也可能出错。点击开始作业后会自动填写和提交，请确认这符合你的使用场景及课程要求。

更多说明见 [模型接口与配置](docs/models.md) 和 [隐私与权限](docs/privacy.md)。

## 常见问题

**更新后提示 `Receiving end does not exist` 或无法扫描？**

扩展重新加载后，旧网页中的脚本可能已失效。刷新教学平台首页，再打开助手扫描。

**“已提交”为什么不是满进度？**

离线作业提交状态与平台计入进度是两回事，通常需要批改。网上作业也可能存在同步延迟，助手会重新从首页进入课程核对。

**视频提示“不允许多窗口播放”？**

先停止任务，关闭重复的视频页，再通过平台正常入口进入。若停用扩展后手动关闭、重开视频仍能复现，请向平台反馈浏览器与页面退出处理问题。扩展不会绕过平台的多窗口限制。

**获取模型失败？**

核对 API 地址、Key、域名访问权限，以及服务是否提供 `/models` 接口。列表里可能含有不支持对话的模型，需要选择支持文字对话的模型。

## 本地开发

Node.js 22 及以上版本：

```sh
npm ci
npm run check
npm test
npm run build
```

`npm run build` 在 `dist/` 生成扩展 ZIP 和 SHA-256 校验文件。扩展自身不需要打包工具或运行时依赖；开发依赖只用于模拟页面测试和生成 ZIP。

```text
extension/   可直接加载的 Manifest V3 扩展
tests/       模拟浏览器、页面、模型接口的回归测试
scripts/     静态检查、测试入口与发布打包
docs/        模型及隐私说明
```

测试使用合成数据，不登录教学平台、不提交真实作业，也不调用收费模型。CI 检查源码、运行测试并验证打包。
